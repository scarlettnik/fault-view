# Backend FaultView

Каталог API и серверной логики. Язык, фреймворк и хранилище будут выбраны отдельно.

При переносе существующего backend скопируйте сюда его исходники, манифест
зависимостей, lock-файл, миграции, настройки и тесты. Оставьте этот README или
замените его инструкцией реального сервиса. Не переносите `.git/`, зависимости,
результаты сборки, локальные базы и `.env` с секретами.

Инструменты и зависимости backend принадлежат этому каталогу. Установка,
проверка и публикация лендинга их не запускают.

Когда сервис появится:

1. Документируйте версии инструментов, команды установки, запуска, миграций и тестов.
2. Добавьте `.env.example` с именами переменных и безопасными примерами значений.
3. Опишите HTTP-контракт в `docs/`; frontend обращается к сервису через API.
4. Добавьте отдельный CI для путей `apps/backend/**`, когда будет что проверять.

Деплой сервиса пока не настроен. Серверный код и секреты не входят в артефакт Pages.
