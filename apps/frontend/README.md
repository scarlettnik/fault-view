# Frontend FaultView

Каталог клиентского приложения. Стек и код будут добавлены отдельно.

При переносе существующего frontend скопируйте сюда его исходники, ресурсы,
манифест зависимостей, lock-файл, настройки сборки и тесты. Оставьте этот README
или замените его инструкцией реального приложения. Не переносите `.git/`,
`node_modules/`, `dist/` и локальные `.env`.

Зависимости устанавливаются из этого каталога. Собственные конфигурации линтеров
и форматирования также храните здесь: правила лендинга к приложению не применяются.
Корневой `package.json` не является npm workspace и не объединяет зависимости.

Когда приложение появится:

1. Документируйте версии инструментов, команды установки, запуска и тестирования.
2. Для конфигурации добавьте `.env.example` с безопасными примерами.
3. Описывайте взаимодействие с API в `docs/`; не импортируйте исходники backend.
4. Добавьте отдельный CI для путей `apps/frontend/**`, когда будет что проверять.

Деплой приложения пока не настроен. GitHub Pages публикует только лендинг.
