FAULT INJECTION

Создайте сбой.
Увидьте его радиус.

Меняется один endpoint. Проверяется весь пользовательский путь: данные, состояния ожидания, fallback и восстановление.

BASELINE / 200 OK

Сначала - здоровый интерфейс.

Зафиксируйте исходное состояние для сравнения. Каталог и рекомендации доступны.

LATENCY / +3 000 MS

Ответ задержался.
Пользователь остался?

Проверьте loading-состояния. Страница должна сохранять контекст, пока ждёт данные.

HTTP 500 / 503

Рекомендации упали.
Каталог исчез.

Найдите неожиданный blast radius: ошибка необязательного блока не должна ломать всю страницу.

TIMEOUT / NETWORK ERROR

Запрос не ответил.
А интерфейс всё ждёт.

Оборвите соединение. Проверьте таймаут, сообщение об ошибке и возможность повторить запрос.

RECOVERY / RETRY

API снова работает.
Интерфейс тоже?

Верните endpoint в строй. Убедитесь, что страница восстанавливается без потери пользовательского контекста.
