# FaultView

Данные демонстрационные; внешние приложения и API не подключаются.

## Как открыть

Откройте `index.html` двойным кликом или перетащите его в браузер.
Рядом должны оставаться папки `styles/`, `scripts/` и `assets/`.

## Файлы страницы

| Файл                 | Назначение                                            |
| -------------------- | ----------------------------------------------------- |
| `index.html`         | Содержание, разметка и подключения стилей и скриптов. |
| `assets/favicon.svg` | Значок вкладки браузера.                              |

### JavaScript

Скрипты подключены с `defer`: браузер выполняет их по порядку после разбора HTML.

| Файл                       | Назначение                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------- |
| `scripts/motion.js`        | Общие функции анимации, ожидания и учёт настройки уменьшенного движения.              |
| `scripts/demo-data.js`     | Демонстрационные маршруты, профили отказа и результаты.                               |
| `scripts/terminal-tabs.js` | Переключение вкладок мышью и клавиатурой, управление фокусом.                         |
| `scripts/mobile-menu.js`   | Открытие и закрытие мобильного меню, удержание фокуса.                                |
| `scripts/terminal-demo.js` | Запуск, остановка и повтор сценария в верхнем блоке страницы.                         |
| `scripts/interactions.js`  | Карта зависимостей, матрица результатов, разбор сбоя и смена сценариев при прокрутке. |
| `scripts/scroll-reveal.js` | Запуск анимаций появления секций и изменение состояния шапки при прокрутке.           |
| `scripts/main.js`          | Связывает компоненты и запускает интерактивность страницы.                            |

## Форматирование и линтеры

Нужен Node.js 22.22+ в ветке 22 LTS или 24.8+:

```sh
npm ci
npm run format
npm run check
```

`npm run format` форматирует исходники, а `npm run check` проверяет форматирование,
HTML, CSS и JavaScript. Любое предупреждение линтера завершает проверку с ошибкой.

### Восстановление зависимостей

Если после изменения зависимостей линтер перестал загружать конфигурацию, установите
согласованные версии из `package-lock.json`:

```sh
npm ci
npm run check
```

`npm audit fix --force` разрешает изменения за пределами указанных диапазонов версий.
Такие изменения могут сделать линтер несовместимым с конфигурацией проекта.

У транзитивной зависимости Stylelint `braces` есть [известная уязвимость](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm),
для которой пока не опубликовано исправление. Это зависимость
инструмента разработки.
