# FaultView

Репозиторий лендинга, клиентского приложения и серверной части FaultView.

## Структура проекта

```text
FaultView/
├── apps/
│   ├── landing/          # Лендинг на HTML, CSS и JavaScript
│   │   ├── index.html   # Разметка и содержание страницы
│   │   ├── styles/      # Стили, адаптивность и анимации
│   │   ├── scripts/     # Интерактивные демонстрации и навигация
│   │   ├── assets/      # Статические ресурсы
│   │   └── tooling/     # Сборка статического сайта
│   ├── frontend/        # TBD — клиентское приложение
│   └── backend/         # TBD — серверная часть и API
├── docs/                # Инструкции по сборке и публикации
├── .github/workflows/   # Проверки и публикация лендинга в GitHub Pages
├── .githooks/           # Локальная проверка перед коммитом
└── package.json         # Команды лендинга для запуска из корня
```

В `apps/landing/` также находятся собственные зависимости, lock-файл и настройки
форматирования и линтеров. Описание файлов и команды — в
[README лендинга](apps/landing/README.md).

Frontend и backend пока не реализованы. Их стек, зависимости, запуск, тесты и деплой — **TBD**.

[Инструкция по сборке и публикации](docs/deployment.md).
